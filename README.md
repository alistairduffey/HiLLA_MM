This repo contains all code to produce the analysis and figures in Duffey et al., 2025: _The global climate response to High-Latitude Low-Altitude Stratospheric Aerosol Injection (HiLLA-SAI) (forthcoming)_

It does not contain code to run the simulations themselves (on three earth system models) or do some initial postprocessing steps, which were carried out on the HPCs that completed the simulations (by Alistair Duffey, Walker Lee, and Lauren Wheeler).
